# 07 · 备份协议 v1

阶段 1 提供字段定义与样例；完整导出、导入校验器、文件选择、覆盖确认和回滚流程在阶段 4 实现。

- [JSON Schema](backup/finance-backup-v1.schema.json)：Draft 2020-12，正式格式标记 `finance-backup`，协议版本 1。
- [最小样例](backup/finance-backup-v1.minimal.json)：一个现金资产、一个零余额快照，其余业务集合为空。仅作协议样例，不是应用默认的九项目数据，也不是已导出的真实备份。

## 1. 字段与数据库映射

顶层固定包含 format、schemaVersion、appVersion、exportedAt、currency、timeZone、data。数据库版本与协议版本分别维护。

| 集合/对象 | 映射与规则 |
|---|---|
| projects | 项目类型 asset/liability/income_log/expense_log；名称使用 nameKey 或 customName；includeInSummary、sortOrder 均保留 |
| balanceRecords | 整数 balanceMinor；以 projectId 关联资产或负债；businessDate、businessTime、orderKey 一起决定先后 |
| projectEntries | 整数 amountMinor；仅关联独立收支项目，方向由项目类型决定 |
| bills | 收入/支出、整数 amountMinor、categoryId、业务时间、备注；没有资产账户关联字段 |
| categories | 收入/支出方向、名称键/自定义名称、排序、isActive |
| memos | 标题、正文、业务日期、tags 字符串列表；数据库内部 tagsJson 在备份中还原为数组 |
| editHistory | entityType、entityId、changedAt、before、after；数据库内部 JSON 字符串在备份中还原为对象 |
| settings | themeMode：system/light/dark；languageMode：system/zh-Hans/zh-Hant/en；currency：CNY；timeZone：IANA 时区标识 |

业务对象的 createdAt/updatedAt 以及历史 changedAt 使用 UTC ISO 8601（以 Z 结尾）。数据库内部以毫秒整数存储，导出时转成字符串，不丢毫秒精度。业务日期为 YYYY-MM-DD、时间为 HH:mm，不使用 UTC 创建时间替代业务日期。

阶段 3 的账单修改历史在 before/after 中额外保留 categoryNameKey、categoryCustomName 名称快照，以便分类迁移删除后仍显示原分类；历史快照内的旧 categoryId 不作为当前业务外键校验。备忘录历史使用 tags 数组，不使用数据库内部的 tagsJson 字符串。正式备份往返应原样保留这些历史字段，协议仍为 v1。

所有金额都是整数分。余额允许 0；收支必须大于 0；单条上限为 999999999999 分。不导出当前余额、变化额、总资产或图表等推导缓存。

项目分类以 categoryKey 保存。内置分类使用 bank 等固定键；阶段 2 的自定义分类使用 `custom:<用户原文>`，例如 `custom:bank`，显示时仅去掉一层前缀，不翻译用户原文。原文最长 80 字符；仍兼容既有未知分类键按原文显示。备份往返必须保留前缀，不能将自定义文本误当内置键翻译；字段类型与协议版本不变。

## 2. Schema 之外的业务校验

JSON Schema 验证字段类型与形状；阶段 4 的应用校验器还必须验证：

- UUID 唯一、父子引用存在、余额/流水对应项目类型、账单与分类方向一致。
- 同项目 orderKey 唯一，名称不能仅含空白；业务时间有效且不晚于账本当前时间。
- 顶层币种和时区与 settings 一致；时区能被应用的时区库识别。
- 修改历史关联对象存在；before/after 的金额字段同样使用整数分。
- 导入资源限制、版本迁移和往返一致性，按文档 03 执行。

恢复采用完整替换，不做合并，不依据文件名猜测格式，不把 URI 当磁盘路径。校验和确认前不得写入业务库；数据库事务不等于外部文件写入事务。先生成可读的恢复副本，再提交替换，保留失败和中断的恢复路径。

## 3. 阶段 1 的检查方式

在 PowerShell 7 中执行：

```powershell
.\scripts\check-backup.ps1
```

该检查验证最小样例符合 Schema，并确认小数“分”被拒绝；不代表备份文件读写或完整恢复已经实现。阶段 4 仍需真实文件往返测试。
