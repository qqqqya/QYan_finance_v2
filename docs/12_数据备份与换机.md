# 12 · 数据备份与换机

适用版本：0.4.0+4。所有账单、资产、独立收支和备忘录保存在本机，没有账号、服务器或自动同步。

## 导出

1. 设置 → 数据管理 → 导出备份。
2. 在 Android 系统窗口选择保存位置，保留自动生成的 .moneybak 文件名或自行修改，然后保存。
3. 看到“备份成功”才表示文件写入并通过回读校验。弹窗显示实际名称、大小和系统可提供的位置。
4. 点击“分享文件”直接打开系统分享面板，可选手机上已安装且支持接收文件的应用；也可以点“完成”。分享面板打开不等于文件已送达，接收情况以目标应用为准。

文件是含 SHA-256 校验和的完整 JSON，包含全部记录、修改历史、项目排序、分类、标签及主题/语言/账本时区设置。它没有加密，请保存在自己控制的位置。私有恢复副本及“最近备份”的设备文件路径不进入导出文件。

## 换机、卸载重装与历史恢复

1. 在旧手机导出完整备份，复制到新手机能通过系统选择器访问的位置；不要只保存应用私有目录。
2. 在新手机安装此应用，进入设置 → 数据管理 → 导入恢复，选择该文件。
3. 核对预览中的日期、账单/账户等数量、金额和设置。确认后会覆盖当前全部数据；V1 不合并、不自动识别其他软件或早期无校验和 JSON。
4. 成功后查看首页、账单和备忘录，并重启一次。主题和语言会按文件恢复，用户文字不翻译。

同一备份反复恢复不会叠加记录。损坏文件、不支持的版本、非法金额/日期/关联或超限文件会拒绝，原数据不变。当前完整文件上限 32 MiB、七类业务集合合计 100,000 条；应用也不导出超过该限制的文件。

每次成功覆盖前，软件在私有 SQLite 事务内保留一份当前数据。数据管理中的“预览并恢复副本”可撤回上次覆盖，仍需确认；恢复后副本切换为本次覆盖前的数据。“删除私有副本”只删这份副本，不删当前账单和外部文件。它不跨卸载保留，不能代替外部导出。

## 正常 APK 更新

同包名、同签名且允许升级的 APK 直接覆盖安装，数据库增量迁移保留已有数据；不用每次手动恢复。不要为解决签名冲突而卸载或清除应用数据。

当前 Android Studio 安装使用 artifacts/finance-stage4-ide-debug.apk；旧脚本交付签名使用 artifacts/finance-stage4-debug.apk。两包同代码、调试签名不同，安装方法见文档 10、11。正式发行签名另属阶段 5，当前包用于测试。

## 恢复出厂

数据管理 → 恢复出厂 → 可选择“先导出备份”。保存成功并关闭成功弹窗后，还需要再次确认清空；取消选择或取消确认不会清空。

确认后清除用户记录、修改历史、设置和私有恢复副本，恢复九个零金额默认项目，语言和主题跟随系统；清理私有分享缓存。已经保存到外部的备份文件会保留。若缓存清理异常，页面提示重试，重启也会继续清理，不虚报完整成功。

“最近备份”显示最后一次成功导出的记录，无法扫描所有目录。如果外部文件被移动、删除或授权失效，重新导出一份即可；目录的移动和删除由系统文件应用管理。
