## 本次实际改动

- 固化 [backup-format.md](backup-format.md)：保留既有 schemaVersion 作为独立格式版本，避免改名使旧 v1 文件失效。无版本号的本项目完整结构按用户决定视为 v0.0，逐级转换后仍做全部业务校验；旧文件无校验和时预览明确提示。未来格式提示先升级，原库不变。
- 新增版本迁移入口和冻结样例回归，支持已知早期无校验和协议样例、正式 v1 及整数 backupFormatVersion 导入别名。当前没有真实 v2/v3 备份，不虚构其业务转换；后续必须补迁移链、文档、Schema、历史样例测试。
- 对照七张 png，保留整行深色资产卡，统一中性强调色、卡片对齐与间距。金额完整缩放显示，零记录/单点/图例逻辑保留；根 Navigator 统一消费左右/底部安全区域。月份/确认弹层可滚动，修复横屏 200% 字体的实际溢出。
- 资产快照汇总改为每次持久化查询快照建立一次索引；账单、项目记录、备忘录每次加载 50 条，筛选变化重置分页，汇总和备份始终使用全部数据。
- 新建持久正式签名，仅存受限且 Git 忽略的 .signing；缺失密钥时 release 构建失败，不回退调试签名。提供旧调试签名兼容包和正式签名 release 候选，迁移边界见 [文档 14](14_签名与安装.md)。

主要文件：lib/domain/backup_format.dart、backup_document.dart；lib/data/workspace.dart；lib/app/finance_app.dart；lib/ui/home_page.dart、app_theme.dart、bills_page.dart、project_detail_page.dart、memos_page.dart、finance_widgets.dart、data_management_page.dart、categories_page.dart；三语资源；android/app/build.gradle.kts；test/data/backup_compatibility_test.dart、test/stage5_layout_test.dart、test/fixtures/backups/；integration_test/stage5_acceptance_test.dart；scripts/prepare-release-signing.ps1、stage5-ui-helpers.ps1、verify-stage5-*、create_stage5_fixtures.dart、install-android.ps1；README、Schema、编号文档及 backup-format.md。

完整 SHA-256、证书指纹与大小见 artifacts/verification/stage5-apk-manifest.json。release 包已在 QA 实际安装、启动、文件恢复和同签名 install -r；Manifest 检查没有 INTERNET 或全盘文件访问权限，只有应用自身的动态接收器权限。debug 包包含 Flutter 调试能力，不作为日常正式发行包。

在 D:\Finance 的 PowerShell 顺序执行：

```powershell
.\scripts\flutter.ps1 run --device-id=emulator-5560
.\scripts\check.ps1
.\scripts\flutter.ps1 build apk --debug
.\scripts\prepare-release-signing.ps1
.\scripts\flutter.ps1 build apk --release
.\scripts\install-android.ps1 -Device <设备ID> -Apk artifacts/finance-stage5-ide-debug.apk -Launch
```

安装脚本默认是 stage5 IDE 兼容包，不会为签名错误自动卸载。正式候选新装/跨调试签名迁移、私钥离线备份见 14；备份恢复方法见 12。没有新增工具安装，复用 Flutter、Android SDK、JDK/keytool。release 第一次构建因 --no-pub 遗留 debug 测试插件注册而失败；从本地 SDK 源码定位后改用正常构建重新生成，最终成功。测试及构建不并行，未手改生成注册文件或删除失败测试。
