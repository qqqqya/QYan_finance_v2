# 09 · 阶段 3 交付与验证

更新：2026-10-22。版本 0.3.0+3，数据库 v1。**阶段 3 已完成并通过限定范围验证**：52 项主机测试、1 项 Android 业务流程、普通 APK 重启保存及旧 IDE 包覆盖升级通过。最终年度横轴截图已复核，QA 数据已清理。本文件只记录真实结果。

## 1. 已实现

- 首页新增月度账单、理财备忘录入口。
- 月份前后切换及年月选择；收入、支出、结余；账单新增、编辑和确认删除。历史月份默认使用该月合法日期；主动跨月保存提示归属月份，提供查看入口，保留原选月份。
- 分类图默认支出，明细默认全部；切换收入/支出图时同步筛选，明细可再切回全部。图例包含名称、金额、占比；零记录为空状态。
- 所选年份 12 个月收入、支出、结余及柱图；跨月、跨年编辑直接从业务日期重算，无统计缓存。
- 分类新增、改名、停用、重新启用。方向创建后固定；停用分类保留在旧账单，旧账单可保留它，新账单不能选择它。类型切换清空原分类，必须重新选择。
- 被引用分类需选择同方向有效目标，事务中迁移全部账单、写逐笔修改历史，再删除分类；不能直接产生孤立账单。
- 备忘录标题、正文、业务日期、标签；关键词与单标签组合筛选、编辑、确认删除。关键词匹配标题、正文和标签，不区分英文大小写；标签精确匹配。
- 账单、分类、备忘录提供可查看和单条/全部删除的修改历史；删除历史不回滚当前内容，删除业务对象级联清理历史。分类迁移历史保留前后名称快照。
- 三语与三种主题沿用全局设置。内置分类翻译，用户名称、标题、标签、正文和备注保持原文。

备忘录输入约束：标题 1–200 字符、正文最多 20,000 字符、最多 10 个去重标签且每个最多 30 字符；中英文逗号或换行分隔标签。账单备注上限 2,000 字符。所有业务日期遵循非未来规则。

## 2. 趋势修正

按本次用户决定覆盖旧文档的阶梯线方案。余额事实仍是快照，同一时刻仍由 orderKey 决定；图上按记录时点等距排列、直线连接。这样同一天的记录不会因时间太近挤成竖线。

界面明确“直线仅示意变化，不代表时间间隔或记录之间的实际余额”，横轴为“记录顺序 · 业务日期”。不绘制伪造的末尾记录；首条前无假曲线，单点/全零仍有独立状态。窗口起点可承接之前已知余额。旧阶段 2 报告保留其当时实现，不作为当前线型约束。

## 4. 命令和测试

在 D:\Finance 的 PowerShell：

~~~powershell
.\scripts\check.ps1
.\scripts\start-emulator.ps1 -Headless
.\scripts\flutter.ps1 test integration_test/ledger_flow_test.dart --device-id=emulator-5560 --no-pub
.\scripts\flutter.ps1 build apk --debug --no-pub
.\scripts\flutter.ps1 run --device-id=emulator-5560
~~~

集成测试会安装测试运行器、可能卸载不兼容测试包并在结束时移除测试应用。仅在可清理的专用设备运行，不能用它检查存有重要数据的手机。普通 APK 安装方法与真机待测清单见文档 10。

原生复验命令为 verify-stage3-upgrade.ps1、verify-stage3-android.ps1、verify-stage3-annual.ps1；均限定专用 AVD。升级脚本依赖本次只读复制到项目临时目录的旧 IDE APK；若清理了该文件，需另行准备旧版同签名 APK，不以卸载用户现有应用来获取它。
