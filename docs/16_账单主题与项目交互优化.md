# 16 · 账单、主题与项目交互优化

更新：2026-10-23。版本 0.5.1+6；本轮是局部改动，复用原账单、图表、项目仓库和确认组件。本轮七项局部优化、主机/模拟器验证及可安装包已交付；真机未测范围列在末尾。未新增软件或依赖。

## 实际行为

1. 月度账单底部常驻“记一笔”，进入即见，滚动图表/明细后仍可直接使用；历史月份默认日期规则保留。
2. 收入/支出和对应分类使用可换行的直接点选项，切换方向清空旧分类；用户自定义分类原文及停用规则保留。
3. 年度页只保留年份、年度收支/结余、带坐标和图例的柱状图及空状态，移除图下十二张重复月度卡片；逐月明细仍在月度账单查看。
4. 设置新增火红、绿、紫、蓝四配色，各自支持跟随系统/亮色/暗黑模式；柔和背景、卡片和清晰强调色全局生效。收入/支出的金额语义继续使用文字、方向及红绿提示，不随主题变义。
5. 卡片底部独立 48dp 把手按住 220ms 后可拖动；边缘滚动改为更细的 16ms 步进，松手原子保存顺序。正文普通滑动不排序。正文长按或上方“更多”打开菜单；菜单入口与把手有独立区域和间隔。
6. 菜单删除和详情删除复用同一确认逻辑；确认显示真实记录/历史数量、不可撤销影响，取消不改数据。确认后事务清理该项目记录和历史，其他项目及独立月度账单不变。
7. 全新初始化/恢复出厂按“大额支出、负债”在前，所有金额仍为零。已有用户顺序、普通升级和导入的 sortOrder 原样保留。

最新决定已同步文档 01/02/03，替代早期“长按只能排序”。配色使用 Flutter 自带 [ColorScheme.fromSeed](https://api.flutter.dev/flutter/material/ColorScheme/ColorScheme.fromSeed.html)，拖动使用原有 [LongPressDraggable](https://api.flutter.dev/flutter/widgets/LongPressDraggable-class.html) 的独立把手与延迟，无新增组件库。

SHA-256、证书指纹和版本信息见 refinement-apk-manifest.json。Release 与调试签名不同，不能跨签名直接覆盖；现有安装选原签名包，同签名升级保留数据。安装脚本不自动卸载解决冲突，签名与迁移步骤见 [文档 14](14_签名与安装.md)。

在 D:\Finance 的 PowerShell 顺序执行：

```powershell
.\scripts\check.ps1
.\scripts\verify-refinement-android.ps1
# 本轮最终构建采用以下当前进程设置；不写入全局环境。
$env:GRADLE_OPTS='-Dorg.gradle.jvmargs=-Xmx1024m'
.\scripts\build-refinement-apks.ps1
.\scripts\install-android.ps1 -Device <设备ID> -Apk artifacts/finance-0.5.1-ide-debug.apk -Launch
```

verify-refinement-* 只允许专用可清理 AVD，会替换/清理 QA 夹具，不在用户手机或原模拟器上执行。Release 全流程命令为 .\scripts\verify-refinement-release.ps1，末次只复核最终包使用 -FinalOnly；保留前一次完整旧版升级证据。当前安装脚本默认选新的 IDE 兼容包。
