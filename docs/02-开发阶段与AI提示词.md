# 开发阶段与 AI 提示词

状态：阶段 0–3 已完成；实际范围、运行命令和证据见 `05_开发进度.md`、`09_阶段3交付与验证.md`；手机与 APK 验证方法见文档 10。文档 06、08 保留先前阶段记录。后续会话先读进度，按用户指定阶段继续，不重复创建工程。

## 1. 推荐技术方案

采用 **Flutter + Dart + SQLite（Drift）**：用户已明确授权该选型并完成阶段 1。先交付 Android，后续复用业务逻辑和大部分界面开发 iOS；仍需管理插件版本，iOS 以后单独适配和验证。

- Flutter 官方提供 [Android 环境配置](https://docs.flutter.dev/platform-integration/android/setup)，并支持后续设置 [iOS 开发环境](https://docs.flutter.dev/platform-integration/ios/setup)。
- SQLite 管理业务数据；[Drift](https://drift.simonbinder.eu/)提供查询订阅、事务和迁移支持，适合解决旧版“数据改了，图表没更新”的问题。
- 按[Flutter 架构建议](https://docs.flutter.dev/app-architecture/guide)分离页面、页面状态、数据仓库和数据库。金额、时间归属、统计规则做成可独立测试的逻辑；不做微服务或复杂企业架构。
- 状态管理先用 Flutter 内置的 ChangeNotifier/ViewModel 配合数据库查询流，路由用 Navigator；避免初期并用多套状态框架。
- 多语言用[官方本地化方案](https://docs.flutter.dev/ui/internationalization)，主题统一管理；安卓返回使用当前稳定版支持的 [PopScope](https://api.flutter.dev/flutter/widgets/PopScope-class.html)等机制，不手写全屏横滑退出逻辑。
- 文件选择与图表库的阶段 0 候选分别为 file_picker、fl_chart；版本、平台能力和许可证核对见 `04_开工准备.md`。在实际引入时验证依赖解析和构建，再保存锁文件，网页核对不代表已构建通过。

用户已明确没有旧源码，阶段 1 已从零创建工程，保留原有 docs/png。本机 Flutter、Android SDK、构建 JDK 与模拟器已配置并实际构建运行；阶段 0 原始核对保存在 `04_开工准备.md`，当前环境以文档 06 为准。

## 2. 什么时候需要哪些软件

| 软件/设备 | 用途 | 什么时候需要 |
|---|---|---|
| Flutter SDK（含 Dart SDK） | 编译、运行、测试跨平台 App | 阶段 1 前；[官方安装入口](https://docs.flutter.dev/install/custom) |
| Android Studio | 安装和管理 Android SDK、模拟器，调试安卓程序 | 阶段 1 前；[官方下载](https://developer.android.com/studio) |
| Android SDK / Platform Tools | 安卓编译与 ADB 真机连接 | 随 Android Studio 的 SDK Manager 配置；具体版本在开工时验证 |
| JDK / JBR | 支撑 Android 构建 | 优先使用 Android Studio 所带、且与构建工具兼容的版本，避免盲目安装多套；[版本说明](https://developer.android.com/build/jdks) |
| Git | 保存每阶段可回退的版本 | 阶段 1 前检查；不要求马上开通远程仓库 |
| 安卓手机 + USB 线 | 验证返回手势、文件读写、键盘和真实布局 | 阶段 1 建议接入，阶段 5 必须真机验收；连接时再指导开启 USB 调试 |
| Android 模拟器 | 补测不同系统、屏幕及字号 | 阶段 1–5；电脑资源不足时优先真机，不必启动多台模拟器 |
| 代码编辑器 / AI coding 工具 | 编写和修改代码 | 使用已有工具；不要求额外购买另一套 IDE |
| Mac + Xcode + iPhone | iOS 构建、签名和真机测试 | iOS 阶段再准备；[Flutter 平台设置](https://docs.flutter.dev/install/custom)要求 iOS 构建环境使用 macOS |

Drift、图表库、本地化库属于项目依赖，不是需要手动打开的新软件。数据库运行在手机应用内，V1 无需数据库服务器、云服务、Docker、Figma 或付费设计工具。

后续 AI 每次发现缺少新软件时，应先告诉用户：**名称、用途、所处阶段、官方安装入口，以及是否可以使用已有工具替代**；不要静默下载大型软件。安装完成后再验证版本和设备连接。

## 3. 阶段大纲

不按固定天数承诺进度；每阶段以可运行成果和对应验收结果结束。前一阶段关键数据问题未解决，不以进入下一阶段掩盖。

| 阶段 | 交付成果 | 通过条件 |
|---|---|---|
| 0：开工前核对 | 需求差异、环境清单、技术选择、页面结构、数据结构及实施清单 | 核心独立记账规则不变；未决假设清楚，工具需求已告知；仍不写应用代码 |
| 1：基础工程 | 可启动 Android App、数据库、金额/时间工具、路由、主题与三语基础 | 本地持久化可验证；初始化为 0；金额和日期边界测试通过 |
| 2：项目与资产 | 首页、四种项目、余额记录、修改历史、总览与图表、拖动排序 | T01–T06、T10–T11、T21 中相关场景通过 |
| 3：账单与备忘录 | 月度账单、分类、年度统计、理财备忘录 | T02、T04、T07–T09、T15 通过；不增加自动资产联动 |
| 4：数据管理 | 正式备份、恢复预览、回滚、恢复副本管理、恢复出厂 | T16–T20 通过；备份真实往返一致 |
| 5：整体验收与交付 | UI 完善、安卓适配、回归测试、可安装包、交付说明 | T01–T24 完成；未通过或未验证项明确列出，不能宣称全部完成 |

主题、语言、导航、金额布局从阶段 1 开始贯彻每个功能，阶段 5 集中检查，不留到最后重新改架构。

## 4. 提示词怎么用

在同一项目中，先发下面的“通用约束”，再发当前阶段提示词。换 AI 会话时重新发送通用约束，让它读取文档与现有代码。**不要一次要求实现全部阶段。**

### 通用约束（每个新会话使用）

```text
你是一名负责 Android 优先的个人财务 App 的移动端工程师。
工作目录是 D:\Finance。先阅读：
- D:\Finance\docs\01-产品需求.md
- D:\Finance\docs\03-数据规则与验收.md
- D:\Finance\docs\02-开发阶段与AI提示词.md
并查看 D:\Finance\png 下对应截图、现有代码和项目说明。

执行用户本次指定的阶段，不擅自扩大范围。用户最新明确决定优先于规划假设；若冲突，先指出并同步文档。
必须遵守：
1. 月度账单、独立收支项目、资产余额互相独立；禁止自动联动。
2. 余额记录是带业务时间的余额快照，不是可累加流水；金额用整数分。
3. 业务日期决定月份；初始金额为 0；所有汇总从持久化数据计算。
4. 时间/金额/备注可编辑，业务记录及修改历史均可删除，但两种删除语义不同。
5. 三语和三种主题模式全局一致；遵守安卓系统返回手势。
6. 备份按文档 03 的统一协议实现，导入失败不能损坏原数据。
7. 不用演示数据、空按钮或“成功”提示假装功能完成；不为通过测试而删除失败测试。
8. 需要新软件时，先告知名称、用途、阶段和官方安装入口；不要静默安装大型工具。

先用简短清单说明本阶段改动，再实施并运行对应验证。
每阶段结束交付：实际完成项、变动文件、运行方式、测试证据、未完成/未验证项。
更新 docs/05_开发进度.md，让下一次会话可以接续；不把“已写代码”写成“已验收”。
```

### 阶段 4：真正可恢复的数据管理

```text
现在执行阶段 4，严格按文档 03 实现 finance-backup v1。
完整 JSON 备份包含所有数据与设置；使用系统文件选择器，支持实际 Android 文件 URI。
按阶段 4 最新决定使用 .moneybak（完整 UTF-8 JSON + SHA-256），实际保存后提供系统分享；不引入服务器、账号、云库或自动同步。普通同签名 APK 覆盖升级保留本地数据库。
实现导入校验、覆盖预览、确认、导入前恢复副本、整体替换事务、失败回滚及恢复副本管理。
V1 只有完整替换，不添加合并导入，也不猜测旧 JSON 格式。
实现恢复出厂：可先导出备份，确认后清除用户数据和私有恢复副本，恢复默认零金额模板。
执行导出→恢复→再导出的字段级一致性测试，以及重复恢复、坏文件、取消、写入失败和中断测试。
执行 T16–T20。只有实际文件写入和恢复成功，才能标记数据管理完成。
```

## 6. iOS 阶段的进入条件

安卓 V1 验收通过，且用户决定开始 iOS 后再推进。准备 Mac/Xcode 与测试设备，复用已有领域逻辑、数据库和备份协议，单独检查 iOS 返回、文件选择、键盘、安全区域、权限和签名。跨平台代码复用不等于无需适配，也不意味着现在需要安装苹果开发工具。
