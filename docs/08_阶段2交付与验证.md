**阶段 2 已完成。** 静态检查、37 项主机测试、1 项 Android 全流程通过；普通包的业务/排序杀进程保存、原生返回、后台恢复及深浅色截图已分段复验。

## 1. 实际完成

- 四种项目均可新增、详情、编辑、删除。支持名称、分类及自定义分类、图标、预设颜色、备注、对应汇总开关；默认项目同样可编辑删除。
- 资产/负债新建默认 0，可填写初始余额与业务时间；独立收支从空明细开始，逐笔累加，可按月筛选。有记录时禁止切换类型。
- 余额与独立收支可新增、编辑金额/日期/时间/备注、单条删除或全部清空。当前余额按业务时间与 orderKey 取最新，不累加快照；编辑不改变 orderKey 和创建时间。
- 项目及业务记录提供前后字段的修改历史，可单条删除或按对象清空。业务时间可编辑，实际修改时刻由系统写入且只读；删除历史不回滚业务金额。
- 删除和清空均说明影响并确认。删除业务记录清理其历史；删除项目清理其记录和历史，不影响账单或其他项目。
- 首页总资产独占一行，分别显示负债与净资产。长按只拖动排序，落点后持久化，靠近边缘可滚动；另有带拖动柄的排序页。删除入口只在详情。
- 总览提供资产、负债构成，图例含名称、金额和占比；正余额才画扇区，全零显示空状态。
- 总览和余额详情有近 30 天/近 12 个月阶梯趋势、日期/金额轴及可展开的时点金额。记录间保持前值，首条前不补假零；单点画点，全部为零显示空状态。
- 总趋势按当前存在且计入汇总的资产重算，页面说明手动记录口径；删除项目或修改汇总开关会重算历史。
- 新页面沿用三语、三种主题和 Android 返回。未保存表单可继续编辑、放弃或保存；提交防重复保存。
- 自定义分类保存为带 custom: 前缀的原文，即使文本等于 bank 等内置键，切换语言也不翻译；字段约定同步到文档 07。

## 3. 运行与复验

工具路径、IDE 环境和模拟器窗口打开方式沿用文档 06，无需重新建工程或安装工具。在 D:\Finance 的 PowerShell 7 执行：

```powershell
.\scripts\flutter.ps1 pub get --offline
.\scripts\start-emulator.ps1
.\scripts\flutter.ps1 run -d emulator-5560

.\scripts\check.ps1
.\scripts\flutter.ps1 test integration_test/asset_flow_test.dart -d emulator-5560 --no-pub
.\scripts\flutter.ps1 build apk --debug --no-pub
.\scripts\verify-stage2-android.ps1
```

集成测试运行器会安装/清理测试应用，只用于专用测试设备。原生脚本也用于初始模板的专用模拟器，会创建临时 QA 项目，验证后删除并恢复卡片顺序。不要在有重要数据的设备运行测试安装器。

本次只操作项目 `emulator-5560`：API 36 x86_64、1080×2400、420 dpi、WHPX。未对用户现有 `emulator-5554`（API 37）安装、卸载或改写数据。

交付包：`artifacts/finance-stage2-debug.apk`；入口 `lib/main.dart`，ARM32 / ARM64 / x86_64，最低 API 29、目标 API 36，调试签名。版本、大小与 SHA-256 见 `artifacts/verification/stage2-apk-manifest.json`。

```powershell
. .\scripts\environment.ps1
& "$env:ANDROID_HOME\platform-tools\adb.exe" -s emulator-5560 install -r .\artifacts\finance-stage2-debug.apk
& "$env:ANDROID_HOME\platform-tools\adb.exe" -s emulator-5560 shell am start -W -n com.example.finance_app/.MainActivity
```
