## 实际完成

开发前核对现有八张业务/设置表、Drift 事务、ChangeNotifier 查询订阅和 Material/三语框架；采用增量开发。数据库 v1→v2 只新增一张本地备份辅助表，既有业务表和资产/账单独立规则不变。未安装新软件；复用已有 Android SDK 官方 SAF / FileProvider。crypto 3.0.7 已在锁文件中，现显式声明为直接依赖。

- 设置 → 数据管理：真实统计、完整导出、系统分享、导入覆盖预览、最近备份、私有恢复副本预览/恢复/删除、可先导出的恢复出厂。所有按钮连接实际操作，支持简中/繁中/英文及全局主题。
- .moneybak 为完整 UTF-8 JSON + 版本 + 规范化 SHA-256；保留全部业务字段、ID、整数分、时间、orderKey、历史、排序、标签和设置。字段细则见 03、07；无合并、旧 JSON 猜测或联网同步。
- Android 实际 content URI 读写：关闭写流后回读比对大小和哈希才报告成功；显示实际文件名/大小/可获位置，FileProvider 临时只读授权调用系统分享面板。取消、权限/空间/IO 错误均不虚报成功。分享缓存有数量/时效限制，恢复出厂清除。
- 校验完成才预览，确认后在同一 SQLite 事务中保存覆盖前私有副本并整体替换。失败/写入中断保持原数据与原副本。恢复副本也需预览确认；外部文件不随副本删除。恢复出厂清理业务、历史、设置和副本，重新生成零金额默认项目；持久化待清缓存标记处理提交后中断。
- 正常同包名、同签名的 APK 覆盖升级保留数据库；卸载仍会清除私有数据，换机方法见 12。

真实模拟器暴露的“系统时钟微秒超过协议毫秒精度”和“恢复语言后成功弹窗短暂混用语言”已修复并加入回归。界面测试的查找范围、异步等待和懒加载定位已修正，未删除失败测试或业务断言。

## 运行与安装

所有命令在 D:\Finance 的 PowerShell 执行，沿用原工具链，无需重新搭建：

```powershell
.\scripts\flutter.ps1 run --device-id=emulator-5560
.\scripts\check.ps1
.\scripts\flutter.ps1 build apk --debug --no-pub
.\scripts\install-android.ps1 -Device emulator-5560 -Launch
```

- 当前 Android Studio 旧包更新：artifacts/finance-stage4-ide-debug.apk，签名 62d56913…；安装脚本默认此包。
